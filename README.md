# CYNO-ESP32-Smart-Desk-Assistant
ESP32-based Smart Desk Companion with OLED Display, Weather Updates, Notifications and Interactive Robotic Eyes.

## Features

* Real-time clock and date
* Weather information via API
* Notification alerts through Wi-Fi
* OLED display interface
* Interactive robotic eye animations
* Touch sensor control
* Timer functionality
* Buzzer alerts

## Hardware Used

* ESP32
* OLED Display
* Touch Sensor
* Push Buttons
* Buzzer Module
* Wi-Fi Connectivity

## Working Principle

1. CYNO connects to Wi-Fi and synchronizes time using an NTP server.
2. The system continuously runs a web server to receive notifications.
3. Incoming notifications trigger OLED alerts and buzzer feedback.
4. Users can switch between clock, uptime, and weather modes.
5. Touch gestures control robotic eye expressions.

## Modes

### Clock Mode

Displays current time and date.

### Uptime Mode

Displays system runtime.

### Weather Mode

Fetches live weather information using an online API.

## User Controls

### Button 1

* Single Press → Uptime Mode
* Double Press → Weather Mode
* Timer Start

### Button 2

* Single Press → 45 Minute Timer
* Double Press → 10 Minute Timer

### Touch Sensor

* Single Touch → Normal Eye Mode
* Double Touch → Angry Mode
* Hold 3 Seconds → Tired Mode
